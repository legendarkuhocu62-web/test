# Финальный экран главы 01 — семь оптимизированных изображений

В папке лежат **семь отдельных WebP**: два фона (desktop/mobile), две иллюстрации глав, знак завершения, домино и лавровый декор. Исходные PNG остаются на Google Диске, в репозиторий после сборки попадают только WebP.

Состояние: **графика загружена, не подключена к интерфейсу и не принята**. Существующую механику, расчёты и рабочий финал не изменять до визуальной приёмки.

### Интеграция без задержек
- Для фона использовать `<picture>` и `<source media="(max-width: 720px)">` либо CSS `@media` — не запрашивать сразу оба фона.
- Не загружать ресурсы финала на стартовом экране. Загрузку соответствующего фона можно начать при переходе к итогам S08.
- Изображения карточек: `loading="lazy"`, `decoding="async"` при вставке как `<img>`; использовать явные width/height.
- Кнопки и тексты должны оставаться HTML, не накладывать целиком статичный скриншот на игру.
- Проверить iPhone Safari и десктоп без кэша, сеть с ограничением скорости, возвращение к итогу и повторное прохождение.

**Важно:** в иллюстрации главы 02 маркировка на контейнере может выглядеть как «3-214» вместо «З-214». Исправить и согласовать до подключения.
