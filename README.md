# ЦЕХ 404 — тестовая сборка первой главы

Состояние на **11.11.2026**. Рабочий репозиторий `legendarkuhocu62-web/test`. Основная резервная публикация `ceh-404-domino` не изменяется.

## Что реализовано в коде
- Вступление S00, пропуск, знакомство с Ириной, производственный отчёт S02 и переговорная S03.
- S04: 13 инициатив A–M, бюджет 100 млн у. е., предварительный выбор и подтверждение.
- EDU-01: проверка технических документов, четыре учебных задания и повторные попытки без штрафов.
- S04-В: возможность сохранить или пересмотреть портфель, отдельное хранение предварительного и окончательного наборов.
- Одна кнопка **«Материалы предприятия»**, две вкладки: **«Материалы предприятия»** и **«Мои решения»**. Справка доступна в соответствующих сценах, скрывает будущие материалы и не меняет игровое состояние.

## Что НЕ завершено
- S05–S08: полные утверждённые тексты и методически проверенные условия отсутствуют; не считать их интегрированными.
- Изучение 3/3 документов и оперативное заключение З-214 в S06 отсутствуют в тестовой сборке.
- Первая попытка EDU-01 и отдельные данные профессионального заключения пока не сохраняются в полном объёме.
- Визуальная приёмка на реальном Android/iPhone/ПК и офлайн-регресс ещё нужны.
- Автоматические тесты GitHub Actions и GitHub Pages нужно сверять по результатам **текущего** коммита, не по старым успешным запускам.

## Проверка новой справочной панели
`tests/materials-panel.test.js` (Playwright) проверяет видимость только изученных документов, историю выборов, закрытие модального окна, возврат фокуса, сохранение введённых ответов и неизменность игрового состояния. Проверка подключена к `.github/workflows/dialogue-tests.yml`.
